# Layer 5 - Data Layer

## Overview

This layer manages all persistent data and external datasets used by the CrisisLink platform.

## Directory Structure

- **postgresql/**: PostgreSQL database schema, migrations, and seeders
- **abs-seifa-data/**: Importing and processing ABS SEIFA 2021 and Census 2021 data
- **datasets/**: Training datasets (Food-101, labeled images for model training)

## Key Responsibilities

1. **Database Management**: PostgreSQL schema for listings, organizations, claims, feedback
2. **External Data Integration**: SEIFA socioeconomic disadvantage indices for regional analysis
3. **Training Data**: Curated food image datasets and demographic data
