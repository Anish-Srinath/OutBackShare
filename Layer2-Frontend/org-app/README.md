# Organization App - Teal Theme

This is the dashboard app for food relief organizations (food banks, meal services, etc.).

## Key Pages

- **LiveListingBoard**: Real-time available food listings
- **Our Needs**: Post food requests
- **Gap Map**: Interactive demand coverage visualization
- **Dashboard**: Main navigation hub with alerts

## Styling

All components use the **Teal** color scheme consistently throughout the app.
